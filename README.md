# JavaScript Practice Repository

This repository is a personal JavaScript learning space where I practise core frontend concepts and browser-based scripting with small, focused examples.

## Overview

The project is built mainly with:
- JavaScript (primary language)
- HTML (UI examples and practice pages)
- CSS (basic styling for some DOM and event exercises)

It is a collection of mini practice files rather than a full application, so each file demonstrates one idea or topic at a time.

## Repository structure

- `Practise files/` - main learning workspace containing individual HTML, CSS, and JavaScript examples
- `README.md` - project overview and usage notes

## Topics covered

The examples include practice on:
- Variables, operators, and conditionals
- Functions and factory functions
- Arrays and array methods
- Loops and strings
- Objects, classes, and prototypes
- DOM manipulation
- Event handling
- Destructuring
- Callbacks and asynchronous JavaScript
- Fetch API and Axios usage
- Local storage

## Example workflow

1. Open the `Practise files` folder.
2. Open any `.html` file in a browser.
3. Check the matching `.js` file for the logic being demonstrated.
4. Experiment by editing values and testing the behavior.

## Notes

This repository is intended for learning and experimentation. It is best used as a reference for JavaScript fundamentals and frontend practice exercises.

## Suggested next step

Use a local web server such as Live Server in VS Code to view the HTML files more smoothly while practising browser-based examples.
